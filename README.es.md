# Instalación

Descarga el código. Puedes hacerlo clonando el repositorio o descargando el archivo ZIP.

## Descargar
Para descargar los símbolos de Inkscape, puedes clonar el repositorio o descargar el archivo ZIP.

### Clonar

```bash
git clone https://github.com/dosis-hardware/dosis-hardware-live-coding.git
```

### Descargar ZIP

Haz clic en el botón verde que dice Code.

![alt text](./assets/code-button.png)

Esto abrirá un menú desplegable en el que puedes hacer clic en **Download ZIP**.

![alt text](./assets/download-zip.png)
## Mover el archivo principal

El archivo principal es [panel-mount-electronics.svg](./inkscape-symbols/panel-mount-electronics.svg), y debe moverse a la carpeta de símbolos de usuario de Inkscape.

Puedes comprobar cuál es la carpeta de símbolos de Inkscape abriendo **Inkscape** y en los menus de la aplicación:

- En Windows y Linux, ve a Edit > Preferences > System.
- En macOS, ve a Inkscape > Preferences > System.

La ruta de la carpeta de símbolos aparece bajo **User symbols** y hay un botón para abrirla.

Si clonaste el repositorio, simplemente mueve el archivo a la carpeta de símbolos de usuario.

Si descargaste el archivo ZIP, descomprímelo y mueve el archivo a la carpeta de símbolos de usuario.

## Nota
Las instrucciones de instalación son importantes porque cada vez que actualicemos el archivo principal, necesitaremos moverlo a la carpeta de símbolos de usuario de Inkscape.
